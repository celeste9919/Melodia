# AI Music Studio - 桌面客户端

## 使用方法

### Windows
双击 `start.bat`，浏览器自动打开应用。

### macOS / Linux
在终端运行：
```bash
chmod +x start.sh
./start.sh
```

或直接双击 `start.sh`

## 前提条件
- 电脑已安装 Node.js（如未安装，请先去 https://nodejs.org 下载安装）

## 首次使用
1. 打开后进入「设置」页面
2. 填入你的 DeepSeek API Key（或 OpenAI Key）
3. 选择模型类型
4. 保存 → 回到「创作」页开始生成音乐

## 分发给他人
将整个文件夹压缩为 .zip 发送即可。对方解压后双击 start 文件。
