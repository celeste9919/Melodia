# AI Music Studio 需求规格说明书

## 1. 项目概述

- **项目名称**：AI Music Studio（AI 音乐工坊）
- **项目类型**：AI 音乐生成 Web 工具
- **目标用户**：通用型（音乐爱好者、创作者、内容创作者等）
- **技术栈**：Vite + React + TypeScript + Tailwind CSS
- **AI 模型**：默认 DeepSeek API，用户可配置其他 API（OpenAI、Claude 等）
- **部署目标**：Web 应用优先 → 后期 Tauri 桌面版
- **AI 编码工具**：Claude Code

## 2. 用户画像

| 用户类型 | 使用场景 | 核心需求 |
|---------|---------|---------|
| 音乐爱好者 | 想体验 AI 生成音乐，无乐理基础 | 简单输入，快速听到结果 |
| 音乐创作者 | 寻求灵感，快速生成 demo | 控制参数，MIDI 导出二次编辑 |
| 内容创作者 | 为视频/播客/游戏配乐 | 风格预设，快速出成品 |

## 3. V1 功能清单

| 优先级 | 功能 | 描述 |
|-------|------|------|
| P0 | 文字描述生成音乐 | 输入 prompt，DeepSeek 生成音乐参数，Tone.js 合成音频 |
| P0 | 音频预览与下载 | 浏览器实时播放 + WAV 导出 |
| P0 | 风格/情绪预设 | 内置风格模板（流行、古典、电子、爵士、摇滚等） |
| P1 | 歌词生成歌曲 | 输入歌词，AI 分析结构并谱曲 |
| P1 | MIDI 导出 | 导出标准 MIDI 文件 |
| P1 | 生成历史记录 | 浏览器本地保存，可回看回听 |

## 4. 输入方式

- 文字描述（prompt）：自由描述想要的音乐风格、情绪、乐器
- 歌词文本：输入歌词，AI 自动配曲
- 风格预设选择：从预设中选择快速启动

*注：参考音频上传为后期扩展功能*

## 5. 输出方式

- 浏览器实时播放（Tone.js Web Audio 合成）
- WAV 文件下载
- MIDI 文件下载

*注：乐谱/五线谱可视化为后期扩展功能*

## 6. UI 规范

- **UI 语言**：中英文切换（react-i18next）
- **UI 风格**：默认深色主题，跟随系统设置
- **自定义主题**：支持用户上传图片，提取配色生成自定义主题

## 7. 数据持久化

- 浏览器本地存储（LocalStorage + IndexedDB）
- 存储内容：生成历史记录、用户配置（API Key、偏好设置、自定义主题）
- 无需后端服务

## 8. AI 实现路径

- DeepSeek API（默认）：负责生成音乐结构参数
  - BPM、调性、和弦走向、旋律音符、节奏型
  - 歌词结构分析、段落分配
- 用户可在设置中配置自己的 API Key 和切换模型
- 音频合成由 Tone.js 在浏览器端完成（非 AI 生成音频）
- **严禁 mock 模式**：无假数据、无示例输出、无硬编码结果

## 9. 后期扩展功能

| 功能 | 说明 |
|------|------|
| 用户登录/账号系统 | 跨设备同步数据 |
| 五线谱可视化 | 音符转为乐谱显示 |
| AI 人声演唱 | 生成带人声的歌曲 |
| 社区分享 | 作品展示和分享 |
| 批量生成 | 多参数批量生成 |
| 音轨混合/编辑 | 多轨道混合编辑 |
| 参考音频上传 | 上传音频模仿风格 |

## 10. 假设与约束

- 假设用户自有 DeepSeek（或其他大模型）API Key
- 浏览器合成音色为合成器风格，非真实乐器采样
- V1 纯前端，无后端服务，无需部署服务器
